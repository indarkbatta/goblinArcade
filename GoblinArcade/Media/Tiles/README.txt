GoblinArcade ecosystem tile art

Place ecosystem terrain assets in this folder and reference them from Studio with addon-relative paths, for example:
  Media/Tiles/orc_crypt_floor.png
  Media/Tiles/orc_crypt_wall.png

Recommended source: square 128x128 art with clear forms. It is rendered into the 96x96 dungeon cells.
PNG/TGA/BLP files bundled with the addon are suitable. Remote web URLs are not.

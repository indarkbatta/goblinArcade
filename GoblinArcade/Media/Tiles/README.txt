GoblinArcade ecosystem tile art

Runtime terrain assets live below this folder and are referenced from Studio with addon-relative paths.

Single-texture fallback examples:
  Media/Tiles/orc_crypt_floor.png
  Media/Tiles/orc_crypt_wall.png

Blob47 wall autotile atlases generated by the Studio Wall Autotile Builder live under:
  Media/Tiles/Autotiles/<ecosystem_id>/<ecosystem_id>_wall_autotile_47.png

The matching JSON mapping is kept beside the PNG as source/control metadata. The WoW runtime does not parse JSON; it reproduces the same normalized 8-neighbor mask order in Lua and selects atlas cells with SetTexCoord.

PNG/TGA/BLP files bundled with the addon are suitable. Remote web URLs are not.
